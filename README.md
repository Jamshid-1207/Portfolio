# Portfolio

My personal portfolio website: who I am, what I build and how to reach me.

🔗 **Live:** https://portfolio-drab-sigma-zyjgpfqv2k.vercel.app

## Pages

- **Home:** intro
- **Projects:** cards with links to the code and live demos
- **About:** short bio and tech stack
- **Contact:** Telegram, email, GitHub

## Tech stack

React 19 · Vite · React Router · CSS

## Getting started

```bash
npm install
npm run dev
```

`vercel.json` redirects every route to `index.html`, so pages like `/projects` open correctly on Vercel after a refresh.
